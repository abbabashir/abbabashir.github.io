# Em & Essence Cosmetics — Retail ERP & Offline-First POS

## Overview
Comprehensive multi-store inventory tracking, point-of-sale, and accounting platform engineered for retail operations with instant offline sync and automated barcode processing.

## Technical Architecture
- **Frontend:** React, Tailwind CSS, Lucide icons
- **Offline Storage:** IndexedDB with bidirectional sync conflict resolution
- **Backend:** Node.js, Express REST API, JWT authentication
- **Database:** MySQL with relational indexing & transaction management
