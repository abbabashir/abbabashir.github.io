# Bicon — Cinema Discovery & Screenings Platform

## Overview
Cinema showtime aggregator and seat reservation experience bridging moviegoers with independent theatres and cinema multiplexes with real-time seat availability.

## Technical Architecture
- **Frontend:** React, Tailwind CSS, Framer/GSAP micro-interactions
- **Backend & APIs:** Node.js, Express, TMDB movie catalog ingestion
- **Location & Booking:** Geolocation API, Webhooks for ticket issuance
