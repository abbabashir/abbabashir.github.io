# BackTrack — AI Powered Lost & Found Community Platform

## Overview
Geo-distributed lost & found recovery ecosystem featuring automated image embedding comparison, spatial matching, and verified claimant verification.

## Technical Architecture
- **Vision & Similarity:** Python, CLIP image embeddings, FAISS vector search
- **Location Services:** GeoJSON indexing, Leaflet / Google Maps Platform integration
- **Stack:** React, Node.js, Express, MongoDB Geospatial queries
