# AI Price Comparison & Decision Support Engine

## Overview
Machine learning multi-vendor price intelligence engine utilizing fuzzy string matching, dynamic web scrapers, and predictive price variance models for consumer procurement.

## Technical Architecture
- **ML / Algorithms:** Scikit-learn, FuzzyWuzzy / RapidFuzz, Linear Regression & Time-Series Forecasting
- **Data Pipelines:** Python, Scrapy, BeautifulSoup, Celery task workers
- **Storage:** MongoDB & Redis cache
- **Frontend Dashboard:** React & Chart.js
